# ai-pixel-forge
Researching AI-driven image processing, computer vision, and visual generation.

## Local reference materials

`LocalReferences/` stores local reference source code, installers, model weights,
archives and datasets. Its entire contents are excluded by the root `.gitignore`
and must not be committed to Git. Create this directory locally after cloning.

The reference directories `AI face swap ` (including its trailing space),
`AI-人脸识别+特征值提取`, and `DeepFaceLab` can be moved into `LocalReferences/`.
Their original root locations are also ignored while that move is pending.

Maintained project source is under `Projects/`.
