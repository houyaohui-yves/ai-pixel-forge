# 第一版验证记录

日期：2026-11-20。工作区：`Projects/image-face-swap/`。

## 环境

- 本机：Apple M1 Pro / 32 GB，macOS arm64。
- Python 3.14.6，PyTorch 2.15.0，NumPy 2.5.5，Pillow 13.0.0，OpenCV 5.1.0.95。
- 检测权重：仓库原有 `DeepFaceLab/facelib/S3FD.npy` 和 `2DFAN.npy`。
- 换脸权重：旧整合包中的 `DFD224F_SAEHD`，`df-d` / 224 / full face，配置记录 377 次迭代。
- 输入：DeepFaceLab 自带文档图片 `doc/replace_the_face.jpg`，1475×1405。没有使用朋友的私人照片。
- 实际安装版本保存在 `requirements-macos-tested.txt`，它记录本机环境，不是已经验证的 Windows 锁文件。

自动化测试覆盖 DFL 对齐与像素重排、融合区域外像素保留、模型格式及缺失权重、受限 pickle、DFLJPG APP15 元数据、重复素材、EXIF 和路径校验。DFLJPG 当前验证了文件内容和元数据契约，尚未在旧版 DFL 训练器中执行完整训练导入。

本机测试产物位于被 Git 忽略的 `data/test-artifacts/`：`http-result.json`、`swap-doc.png`、`swap-mask.png`、`detection-doc.jpg`、`workspace-ui.jpg`、`library-ui.jpg`。素材库中的“验证样例（官方文档）”是验收样例，可与朋友资料分开使用。

MPS HTTP 首次样例推理记录约 917 ms，浏览器后续缓存模型后约 0.1 秒；这些是单次单脸处理记录，不包含所有上传/检测时间，也不是视频速度或普遍性能承诺。

## 仍未验证或尚未实现

- Windows 实机和 RTX 3070 Ti / CUDA 尚未验收；已提供跨平台代码、依赖安装说明和 BAT 启动器。
- 尚未进行 TensorFlow 原实现与 PyTorch 移植的逐层、全网络数值对照。

- 当前环境使用 NumPy 2；NumPy 1 的模块路径兼容分支已加入，但没有另建 NumPy 1 环境进行实测。
- 没有朋友专属模型、身份相似度评测或覆盖不同姿态/光照/遮挡的质量基准。历史样例成功不代表朋友照片能达到同样效果。

第一版验收结论：当前 Mac 上的本地图片处理和素材整理流程可运行，核心可由后续视频程序复用。跨平台实机验收、朋友模型训练及画质评估是后续独立工作，未计为已完成。

## 相机照片尺寸限制修复

针对 6192×4128（25,560,576 像素）照片被拒绝的问题，将导入上限从 2400 万提高到 6400 万像素，Pillow 检查与应用上限同步，错误提示也从同一常量生成。导入和输出保留完整尺寸。

- 新增真实 6192×4128、300 DPI 的 PNG 解码回归，确认尺寸和角落像素不变；另验证 6400 万边界准入、超限提前拒绝及过窄图片的提示。旧实现下新用例有 4 项失败，修复后存储模块 13 项全部通过。
- 修复后完整自动化测试：45 项通过。
- 使用官方文档人脸制成同尺寸测试图，在 CPU 上实际完成 `Runtime.analyze` 和 `Runtime.swap`：检出 1 张脸，输入与输出均为 6192×4128，导入源图像素保持一致，输出遮罩外像素保持一致。不是对用户原照片的画质验收。
- 此次完整流程约 3.67 秒，进程峰值内存约 3493 MiB；仅代表这张测试图和本机环境。结果记录在 `data/test-artifacts/highres-validation.json`。
